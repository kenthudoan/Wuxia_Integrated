# 64px 地形自动拼接 · v1

## 支持范围

|区域|可连接的地表组合|
|---|---|
|城镇|草地/石板路；草岸/水面|
|山林|草地/土路；草地/石路；土岸/水面|
|雪山|积雪/山路；积雪/融雪地；雪岩岸/冰溪|
|沼泽|湿草/泥地；泥岸/水面|
|沙漠|沙地/碎石路；沙地/干裂地；沙地/绿洲草地；岩岸/水面|

共14组。每组47种邻接形态（独立块、端点、直边、转角、内角、交叉及孔洞），每种3个纹理变化，共1974个前景图集格。变化版复用同一材质及轮廓，不能说成1974种全新手绘地形。格子64×64、像素硬边、前景透明；填满单格时的可见小岛/窄路宽度约32px。

底图使用256或512px原尺度连续材质区，按坐标取64px切片；前景变化版共享窄边缘，避免不同变化相邻时出现透明裂缝。周期边缘与前景变化的接合带有派生像素，不宣称逐像素保持全部原图。

## 文件

`*_Tiles.tres`是切片画刷；自动连接资源位于connected子目录。

## 运行和操作

打开本工程，运行 `BuyerKit/TerrainLab.tscn`；也可在原环境查看器按T进入，Esc返回五地图。

- 鼠标左键拖动：铺设前景；右键拖动：擦除并自动修补周边。
- 下拉菜单：选择14种组合；1～5切换环境首组；N切换下一组。
- WASD/方向键：移动金色测试标记；水面有碰撞，其他组合可通行。
- R恢复示例，C清空前景，G显示网格。恢复、清空和切换会丢弃练习图里的临时绘制；运行模式不自动写文件。

## 在Godot编辑器里搭自己的地图

1. 打开对应 `*_example.tscn`，另存为新场景；保留Base与Terrain两个TileMapLayer。
2. 地图扩展时，在Base层按大底图原顺序铺设，横纵坐标分别对base_columns/base_rows取余，保持纹理相位。可以选中完整底图矩形作为多格画刷连续盖章；不要随机打乱Base切片。
3. 选择Terrain层，在编辑器TileMap的Terrains页选择本组地形及Connect模式，绘制、擦除。资源已配置Sides+Corners，不用逐格选内外角。
4. 用代码铺设时调用 `layer.set_cells_terrain_connect(cells, 0, 0, false)`；擦除调用同一方法，terrain参数改为-1。最后的false让空白邻居参与边缘匹配。
5. 多种前景可用不同TileMapLayer叠放；底层只铺一次。各层仍使用自己的二元组合，三种材质在同一交点相遇时需要人工确认层序与遮挡。
6. 五组水面已带TileSet物理碰撞，原点位于格子中心；透明的岸边可走，水域实心部分不可走。不要再给整个64px水块添加整格碰撞，以免挡住岸边。

PNG可供其他引擎使用；邻接掩码位次为N/E/S/W/NE/SE/SW/NW，斜角只有相邻两条边都连接时才有效。Godot的自动选块与碰撞配置不会随PNG自动迁移到其他引擎。

## 验证与边界

本版支持上表14种二元地表组合，不是35种材质任意互混。未新增断崖、高差、瀑布、动态水面或三材质自动交汇规则；原整地图底图仍保留，尚未把五张成图整体改造成TileMap。雪地拼接PNG不自动带原雪面Shader/脚印，需按REBUILD_GUIDE绑定。
