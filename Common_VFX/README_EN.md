# Free Common VFX — Six Techniques + Sword Arc

Open project.godot with Godot and run. Select a skill or run its Demo.tscn with F6. WASD/arrows move; Space casts; hold/release Space for Ink Slash; H resets. J/K/L select the sword-arc phases. This reference project reuses existing PNG/WAV and visual algorithms, with a small code-drawn test floor rather than the full town. Six techniques plus one three-phase sword-arc family are supplied, not seven new characters or a complete game.

Each skill folder contains its demo and source, plus PNG assets where applicable. Shared contains one copy of actor/demo actions, targets, 20 sound cues and runtime support. For a single skill, include Shared, that folder, catalog.json and the project/gallery entry files. Other skill folders are optional. Raw PNG frames alone do not reproduce procedural motion or shaders. Preserve anchors, timing, logical dimensions and transparent blending when porting.

See README.md for the per-skill links.
