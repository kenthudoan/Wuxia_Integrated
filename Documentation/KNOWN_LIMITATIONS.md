# 使用范围 / Usage scope

- 本档包含34位完整五动作人物，23位另附第二套攻击。方向、帧数及事件以各动作JSON为准。另附一位斗笠侠客：32组、240张PNG，缺少独立Hurt；按附赠有限动作角色使用。
- 门派技能为七派共用21招，不是每位人物各有三套独占技能。玄霄掌门有一组四向通用Cast，其他人物不因此获得专用施法。特效的完整表现依赖配套轨迹/Shader。
- Boss特效按VFX/CHARACTER_SKILL_BINDINGS.json匹配：黑风大王、赤目虎君的动作角色未提供，不是黑风寨主、吊睛猛虎的别名；反派不保证每人均有专属技能。
- 五地图、建筑/物件、UI和地形仅在相应档位提供。A6为固定地块相位；Connected_14为二元地形连接，不支持任意三材质交汇或自动高差。部分地形为底图或手工多边形，物件可独立编辑。
- 开门版为静态外观，不含连续门动画或自动碰撞切换；UI、背包和任务内容为示例数据。玄霄剑宗独立地图扩展包及室内不包含在这四档中。
- PNG/WAV可跨引擎使用，Godot运行代码需移植；不提供完整战斗/存档/任务系统。支持环境为macOS/Godot4.7.1 Compatibility，其他平台未验证。
- AI辅助内容；使用权、修改与再分发边界以许可证和第三方声明为准。

Not every feature is included in every product. See SKU.json and the bundled asset catalogs for this product's contents. Engine-specific runtime behavior must be ported for other engines.
