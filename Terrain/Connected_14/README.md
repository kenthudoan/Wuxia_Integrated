# 14组二元连接图集

每组base图4×4个64格；edges图按catalog.json/pairs/tiles的atlas坐标取64×64区域。mask位0至7依次为上、右、下、左、右上、右下、左下、左上；置1表示该侧/角连接前景，置0表示不连接。base层先铺，edges透明过渡层叠在其上；47形、每形3变体。14组是材质组合，不是1974个独立环境物件。附带Godot_Examples/Environment_5含实际使用逻辑；本目录是跨引擎源PNG和索引，其他引擎需自行接入相同邻域规则。

这是二元连接系统，不承诺任意三种材质、高差和岸墙。A6固定相位小套件独立于本图集，不可混用规则。
