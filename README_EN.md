# Wuxia Pixel Assets — 整合包 / v1.1.3

34 complete five-action characters; 23 include alternate attacks. Idle/Walk use eight directions; Attack/Hurt/Death use four. Read [the animation library](Characters/ANIMATION_LIBRARY.json) and preserve canvas, anchor, durations, loop and end behavior. Use nearest filtering.

Includes one limited-action straw-hat hero bonus: 240 PNGs in 32 clips, without a separate Hurt action.

See [Chinese guide](README_中文.md) for example-project links, [scope](Documentation/KNOWN_LIMITATIONS.md), [license](Documentation/LICENSE.txt) and [third-party notices](Documentation/THIRD_PARTY_NOTICES.md). Open a bundled project.godot to run its example. PNG/WAV assets work across engines; Godot scripts, shaders and widgets require porting. Source PNG playback alone does not reproduce procedural VFX. AI-assisted content. Tested platform: macOS/Godot4.7.1 Compatibility.
